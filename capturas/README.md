# Carpeta de capturas para la documentación de IA

Esta carpeta contiene **archivos placeholder** (rectángulos de color) que deben
ser reemplazados por **capturas reales** tomadas por el estudiante de su propia
sesión con la herramienta de IA utilizada.

Los archivos actuales solo sirven para que las referencias de
`DOCUMENTACION_IA.md` no queden rotas. **No representan capturas reales.**

## Cómo reemplazarlas

1. Toma una captura de pantalla de la conversación real con la herramienta de IA
   (ventana del chat donde se ve el prompt y la respuesta).
2. Guarda la imagen con exactamente el mismo nombre de archivo, sobrescribiendo
   el placeholder (formato recomendado: PNG o JPG, 1920×1080 o mayor).
3. La tabla de `DOCUMENTACION_IA.md` (sección 7) indica qué captura va en cada
   archivo.

## Archivos y su contenido esperado

| Archivo | Captura que debe contener |
| ------- | ------------------------- |
| `captura-herramienta.png` | Pantalla del asistente de IA con el modelo usado |
| `captura-prompt-1.png` | Prompt inicial enviado (pedido del proyecto) |
| `captura-prompt-2.png` | Prompt de estructura y datos JSON |
| `captura-prompt-3.png` | Prompt de vistas con lectura de JSON |
| `captura-prompt-4.png` | Prompt de templates con herencia |
| `captura-prompt-5.png` | Prompt de estilos y validación |
| `captura-respuesta-codigo.png` | Ejemplo de código generado por la IA |
